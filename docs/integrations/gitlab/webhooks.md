# Webhooks GitLab

O adapter deve suportar webhooks de projeto ou grupo para Issues, Notes, Merge Requests e mudanças relevantes do projeto. Validar o token/configuração do webhook conforme a instância, registrar o identificador de delivery quando fornecido ou derivar uma chave estável, responder rapidamente e processar de forma assíncrona.

Referências: [webhooks](https://docs.gitlab.com/user/project/integrations/webhooks/) e [eventos](https://docs.gitlab.com/user/project/integrations/webhook_events/).
