# GitLab API adapter

O adapter GitLab usa REST para Projects, Issues, Notes, Merge Requests, hierarquia e issue links. O `Project` GitLab é normalizado como `Repository`; ele não é equivalente ao GitHub Project de planejamento.

Referências oficiais:

- [REST API](https://docs.gitlab.com/api/rest/)
- [Projects](https://docs.gitlab.com/api/projects/)
- [Issues](https://docs.gitlab.com/api/issues/)
- [Notes](https://docs.gitlab.com/api/notes/)
- [Merge Requests](https://docs.gitlab.com/api/merge_requests/)
- [Issue links](https://docs.gitlab.com/api/issue_links/)
