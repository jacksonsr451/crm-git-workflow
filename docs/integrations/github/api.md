# GitHub API adapter

O adapter GitHub usa REST para Issues, comments, sub-issues e dependencies. GraphQL só deve ser usado quando reduzir round trips ou for necessário para Projects, após contract test.

Referências oficiais:

- [Issues](https://docs.github.com/en/rest/issues/issues)
- [Issue comments](https://docs.github.com/en/rest/issues/comments)
- [Sub-issues](https://docs.github.com/en/rest/issues/sub-issues)
- [Issue dependencies](https://docs.github.com/en/rest/issues/issue-dependencies)
- [Pull requests](https://docs.github.com/en/rest/pulls/pulls)
- [Repositories](https://docs.github.com/en/rest/repos/repos)
