# Autenticação GitHub

GitHub App é o mecanismo principal para produção. A instalação define o escopo de repositories e o adapter solicita apenas permissões necessárias, como Issues, Metadata e Projects quando usados. PAT é aceitável apenas para desenvolvimento controlado, não como arquitetura SaaS.

Referências: [GitHub Apps](https://docs.github.com/en/apps/creating-github-apps), [permissões](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/choosing-permissions-for-a-github-app) e [rate limits](https://docs.github.com/en/rest/using-the-rest-api/rate-limits).
