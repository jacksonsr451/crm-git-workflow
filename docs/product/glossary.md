# Glossário

- **Issue**: tarefa nativa do GitHub, fonte de verdade de conteúdo e estado base.
- **Sub-issue**: Issue vinculada como filha de outra Issue.
- **Projection**: representação local derivada para consulta e desempenho.
- **Workflow stage**: valor de status de gestão, preferencialmente campo single-select `Status` de um GitHub Project.
- **Dependency**: relação nativa `blocked by` entre Issues; não implica stage BLOCKED.
- **Structured update**: comentário GitHub normal com metadata local de tipo.
- **Webhook event**: entrega HTTP recebida do GitHub.
- **Domain event**: fato interno relevante após uma mudança aceita.
- **Integration event**: mensagem interna para coordenar integração externa.
- **Audit event**: registro imutável de ação do produto.
