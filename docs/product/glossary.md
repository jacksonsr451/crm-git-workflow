# Glossário

- **SCM provider**: serviço externo que mantém repositories/projects e seus work items.
- **Provider connection**: autorização e endpoint de um provider dentro de um workspace.
- **Repository**: container normalizado; corresponde a Repository no GitHub e Project no GitLab.
- **Work item**: unidade normalizada; corresponde principalmente a Issue.
- **Sub-issue**: work item vinculado como filho de outro work item.
- **Projection**: representação local derivada para consulta e desempenho.
- **Workflow stage**: valor de status de gestão, nativo do provider quando bound ou configuração local de apresentação.
- **Dependency**: relação externa entre work items; não implica stage BLOCKED.
- **Structured update**: comentário normal do provider com metadata local de tipo.
- **Webhook event**: entrega HTTP recebida de um provider.
- **Domain event**: fato interno relevante após uma mudança aceita.
- **Integration event**: mensagem interna para coordenar integração externa.
- **Audit event**: registro imutável de ação do produto.
